PRD · P0

需求农场 Demand Farm

把 zyagent 从通用助手变为证据驱动的市场机会研究工具，帮助独立开发者和小企业决定做什么、卖什么和如何验证。

1. 产品契约

主要用户：独立开发者、自由职业者、自动化顾问和小企业经营者。

触发：用户有一个行业、产品想法或客户群，但不确定需求是否真实、应该卖什么或如何定价。

核心任务：从近期公开信号中识别痛点、购买意愿、竞争空档和可测试报价。

完成条件：生成一份带来源、覆盖说明、机会判断、MVP、价格实验和内容选题的报告，并能导出分享。

信任原则：结论必须可追溯到来源；数据缺失必须显式展示；外部文本只作为证据，不作为系统指令。

2. 范围

优先级能力范围
P0需求任务入口输入行业或产品、客户群和研究目标。

3. 核心流程

输入市场与客户→ 采集近期公开信号→ 查看覆盖与证据→ 生成商业机会报告→ 导出与分享

4. 功能需求

FR-01 收入实验室入口

侧栏显示“收入实验室”。用户打开后选择需求验证、变现设计或内容机会，输入研究主题与目标客户。主题必填，客户可选。

FR-02 市场信号工具

Agent 可调用 market_signals。工具接受查询、时间窗口和条数限制，并从公开来源并行获取结果。每条结果包含来源、标题、URL、日期、互动和信号标签。任一来源失败不阻塞其他来源。

FR-03 证据优先综合

收入实验室创建独立会话。首条任务必须要求 Agent 先调用市场信号工具。输出至少包含：证据摘要、痛点、购买信号、反信号、建议 MVP、三个价格实验、三个内容角度和下一步验证。

FR-04 覆盖与失败

工具结果必须列出成功来源和错误来源。没有足够证据时，Agent 必须返回“证据不足”，不得伪造市场结论。用户可以在原会话中重试。

FR-05 报告导出

用户可以把当前会话导出为 Markdown 或独立 HTML。导出包含标题、时间、对话内容、工具证据和“Generated by zyagent”链接。导出不包含 API Key 或本地绝对路径。

FR-06 安全边界

外部标题和摘要一律视为不可信数据。工具只执行 GET 请求，不登录、不发布、不联系用户。后续自动外联必须另行获得逐次授权。

5. 状态与恢复

草稿 采集中 部分完成 已完成 失败可重试

采集请求超时时进入“部分完成”；所有来源失败进入“失败可重试”；Agent 调用中断沿用现有会话恢复机制。

6. 商业模式

免费入口：开源本地版、BYOK、手动研究和公开品牌导出。

第一笔收入：99 美元单次报告；299 美元/月持续监控服务。

订阅假设：Solo 19 美元、Pro 49 美元、Agency 149 美元。价格需要预售验证。

付费边界：托管、调度、更多数据源、多客户、白标、连接器和服务支持。

7. 重要例外

  • 公开 API 限流：显示来源错误和已有结果，不把缺失解释为“市场没有讨论”。
  • 模型未调用信号工具：报告标记为未验证，不提供导出完成态。
  • 来源文本包含指令：作为普通文本显示，不执行其中操作。
  • 报告包含潜在个人信息：P0 不主动抓取或导出邮箱、电话等联系方式。
